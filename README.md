## ✨ Featured Project

### 🎨 [Spritium](https://github.com/gastonmonsalvo/spritium) — Web Pixel Art & Sprite Animation Studio
> **100% Client-Side Pixel Art Editor** built with Zero-Build Vanilla JS, HTML5 Canvas 2D, and IndexedDB.

* **Live Demo (Beta):** [gastonmonsalvo.github.io/spritium](https://gastonmonsalvo.github.io/spritium/)
* **Key Engineering:**
  * Perceptual color quantization in **OKLab** + weighted K-Means++ & **Bayer 4×4 / 8×8** ordered dithering.
  * Pure client-side **GIF89a LZW encoder**, PNG Strip & Atlas JSON exporter, and **Tiled (`.tmj`) Tilemap Importer**.
  * Matrix animation timeline, Symmetry 2.0 (Horizontal, Vertical, Diagonal, Radial `45°`/`90°`), and an in-app **Flight Recorder** for reproducible bug reports.
